# SpeakType v2.2.16

Released: 2026-05-08

## Focus

This release completes the setup wizard's ASR download failure state so the transition from "downloading" to "failed" is coherent.

## Changes

- A failed ASR model download now re-renders the full Speech Recognition Model step in error mode.
- The error state keeps the readable failure message, retry action, and download-later action while restoring the explanatory hint beneath the error.
- The previous progress bar is cleared as part of the rebuild, so the failed state no longer carries any misleading in-progress UI.
