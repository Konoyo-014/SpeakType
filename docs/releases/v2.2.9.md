# SpeakType v2.2.9 Release Notes

SpeakType v2.2.9 rebuilds Dictionary & Snippets for the V2.2 adaptive-hotword workflow. The previous window placed custom vocabulary, snippets, and correction rules into one long scrolling form, which made it easy to lose context while editing and gave add/remove actions almost no visible confirmation.

The editor now uses a native left navigation rail with separate sections for Custom Dictionary, Snippets, and Corrections. The right side shows only the active editor, with live counts at the top and a fixed footer status line at the bottom. Adding a word, adding a snippet, updating a correction, trying an empty input, trying a duplicate word, deleting an item, switching sections with unsaved changes, and saving all produce visible state.

Real Computer Use testing caught an important second-order issue in the first rebuild: the snippet text field was still too narrow for realistic long snippet bodies. Snippet and correction inputs now use stacked rows so long replacement text has the full content width, while list rows preserve full text instead of truncating snippet bodies before display.

Verification completed for this release includes source compile checks, targeted dictionary-window tests for section order, row formatting, counts, and dirty-status reset, real Computer Use checks for the native dictionary editor, full Python test suite, diff whitespace checks, clean temporary DMG build, mounted-app metadata checks, bundled import version check, and mounted-app strict codesign verification.
