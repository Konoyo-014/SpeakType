# SpeakType v2.2.14

Released: 2026-05-08

## Focus

This release hardens the first-launch ASR model download path that users reach from the setup wizard.

## Changes

- Made the Hugging Face download progress wrapper compatible with the `name="huggingface_hub.snapshot_download"` argument passed by newer `huggingface_hub` releases.
- Kept byte progress callbacks for the setup wizard while avoiding a raw `Unknown argument(s)` failure in packaged macOS builds.
- Replaced raw setup-wizard download exceptions with localized, user-readable states for downloader incompatibility, missing models, network/Hugging Face service failures, and unknown failures.

- `venv/bin/python -m pytest -q`
