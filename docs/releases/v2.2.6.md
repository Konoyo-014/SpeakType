# SpeakType v2.2.6 Release Notes

SpeakType v2.2.6 tightens the floating recording HUD after real macOS testing found that the completion preview could allocate two lines of height while the underlying `NSTextField` still drew the final text as one clipped line. The HUD body now uses a transparent, read-only native `NSTextView`, so long CJK text and mixed technical terms such as `Qwen3-ASR`, `mlx-audio`, and `TransformerEngine` wrap as they are actually displayed.

The overlay also now computes its width from the current visible screen frame. On normal displays it keeps the familiar 460pt native pill, while narrow spaces and split-screen layouts shrink safely inside the available screen bounds instead of relying on a fixed width.

Verification completed for this release includes source compile checks, targeted status-overlay tests with responsive geometry coverage, real Computer Use checks for final-result, recording with active hotwords and whisper indicator, long streaming preview, polishing, and error HUD states, full Python test suite, diff whitespace checks, clean temporary DMG build, mounted-app metadata checks, bundled import version check, and mounted-app strict codesign verification.
