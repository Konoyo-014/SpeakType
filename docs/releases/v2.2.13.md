# SpeakType v2.2.13

Released: 2026-05-08

## Focus

This release tightens high-frequency Chinese UI polish in the global menubar and first-launch completion path.

## Changes

- Localized compact hotkey display names across the menubar, ready notification, and setup completion step. Chinese UI now shows `快捷键：右 ⌘`, `左 ⌘`, `右 ⌥`, `右 ⌃`, and `⌃⇧空格` instead of English fragments.
- Added one shared localized hotkey-display helper so future hotkey surfaces do not drift apart.
- Localized the About notification body from `Backend:` to `识别后端：` in Chinese UI and updated the copyright line to `© 2025-2026 SpeakType`.
- Changed the Speech Recognition Model step in the setup wizard from automatic download to explicit user action. The wizard now shows `下载模型` and `稍后下载` before any network download starts.
- Localized the initial ASR download status from `Starting...` to `正在准备` in Chinese UI.
