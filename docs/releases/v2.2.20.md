# SpeakType v2.2.20

Released: 2026-05-08

## Focus

This release makes the Adaptive Hotwords window's Reveal File action visibly accountable inside the window.

## Changes

- Reveal File now reports whether the hotword file was revealed or the configuration folder was opened.
- The Adaptive Hotwords footer feedback line now consistently handles copy, refresh, and reveal outcomes.
- Missing hotword files remain a normal first-run state; the app opens the config folder and explains that result.
