# SpeakType v2.2.21

Released: 2026-05-08

## Focus

This release removes stale blank scroll space from the Local Diagnostics window when the report list returns to a running or empty state.

## Changes

- Local Diagnostics now resets the row document height when stale rows are removed and the fallback status row is shown.
- Populated diagnostics reports still grow from their actual wrapped row content, preserving readable long details and actions.
