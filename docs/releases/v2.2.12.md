# SpeakType v2.2.12 Release Notes

SpeakType v2.2.12 improves the first-launch setup wizard. Real Computer Use testing of the Text Polishing step showed that the Chinese UI still mixed in English labels such as `Ollama Service` and `LLM Model`, and Copy Command buttons gave no visible confirmation after writing commands to the pasteboard.

The Text Polishing step now uses localized readiness labels: `Ollama 安装`, `Ollama 本地服务`, and `润色模型`. The Chinese model status text also consistently refers to the polishing model as `润色模型`, matching the visible section label.

Copy Command buttons now confirm success in place. After the user copies `ollama serve` or `ollama pull ...`, the clicked button changes to `已复制`, so users can tell which command was copied without checking the clipboard manually.

Verification completed for this release includes source compile checks, targeted setup-wizard tests for localized LLM-step labels and copy confirmation text, real Computer Use checks for the native setup wizard LLM step, both copy commands, visible copied confirmation, full Python test suite, diff whitespace checks, clean temporary DMG build, mounted-app metadata checks, bundled import version check, and mounted-app strict codesign verification.
