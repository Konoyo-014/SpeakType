# SpeakType v2.2.2 Release Notes

SpeakType v2.2.2 is a focused UI and interaction hardening release. It follows the v2.2.1 adaptive-hotword interface work and fixes the remaining real-window issues found during macOS Computer Use testing.

The local diagnostics window now renders long readiness details and repair actions as variable-height wrapped rows. This matters most for local Ollama failures, where the user needs to see both the persistent startup option and the temporary `ollama serve` command directly in the window instead of relying on the copied report.

The first-launch setup wizard now has a wider, more stable layout. Command fields span the available width, Copy Command buttons sit below the command fields, and primary actions stay consistently right-aligned. Long model commands such as `ollama pull huihui_ai/qwen3.5-abliterated:9b-Claude` are visible in full and still copy completely to the clipboard.

Verification completed for this release includes the full Python test suite, source compile checks, diff whitespace checks, real macOS Computer Use passes for Diagnostics, Setup Wizard, Preferences, Dictionary, Statistics, and the recording HUD, followed by DMG verification, mounted-app version checks, bundled import version checks, and mounted-app strict codesign verification.
