# SpeakType v2.2.11 Release Notes

SpeakType v2.2.11 tightens the Statistics window localization. Real Computer Use testing showed that the Chinese interface still displayed duration units such as `min` and `s`, and the recent 7-day activity labels used English weekday abbreviations.

The Statistics summary, metric tiles, and recent-dictation metadata now use localized duration strings. In Chinese, total duration and average duration are shown with `分钟` and `秒`. The recent 7-day activity labels now use `周一` through `周日`, which keeps the whole dashboard in the same language as the rest of the app.

Verification completed for this release includes source compile checks, targeted statistics-window tests for localized duration units and Chinese weekday labels, real Computer Use checks for the populated native Statistics window, scrolling through long recent-dictation rows, footer control visibility, full Python test suite, diff whitespace checks, clean temporary DMG build, mounted-app metadata checks, bundled import version check, and mounted-app strict codesign verification.
