# SpeakType v2.3.0

Date / 日期：2026-11-01

## English

### Dictation history and text recovery

- Open **Dictation History** from the menu bar to search original transcription, final text, app name, time, or insertion result.
- Select a record to read the complete original and final text. Separate copy buttons preserve the selected text, including line breaks and Unicode characters.
- Refresh updates the list while retaining the selected record when it remains visible. Empty history and searches without matches show distinct messages.
- Export history as TXT, Markdown, CSV, or JSON. **Dictation Statistics** remains available as a separate menu item.
- With history enabled, normal dictation saves the original transcription before local polishing and saves the final result before insertion. A polishing or insertion error leaves the saved text available for recovery.
- History identifies **Unconfirmed**, **Inserted**, **Sent, unverified**, and **Failed** results. Sent-but-unverified means input was sent but the target did not provide enough information to confirm insertion.
- **Copy Last Dictation** copies the latest available result. **Insert Last Dictation Again** inserts it into the currently focused app. The current session retains the latest result even when persistent history is disabled.
- Normal dictation, snippet expansion, and selection editing save their available original and final text before attempting insertion.
- Older records without an insertion outcome are shown as **Sent, unverified**.

### Safe voice undo

- `undo that`, `scratch that`, and `撤销刚才` can remove a verified insertion while the same input field, full text, and cursor position remain unchanged.
- The saved cursor and selected range use UTF-16 positions, so text containing emoji and other Unicode characters is selected accurately.
- Undo selects the exact inserted span through Accessibility, checks the target again, deletes that selection, and verifies the expected text.
- Moving the cursor, selecting other text, editing the document, switching documents, or using a target without readable Accessibility text leaves the current text unchanged.

### Language, permissions, and model readiness

- Polish-only prompts preserve the input language, and retries retain the requested language. Language checks reject obvious Latin/CJK script changes, including short English input.
- Setup and diagnostics read actual microphone authorization and check the input permissions used for recording, hotkeys, and text insertion.
- Ollama availability checks use the configured service address and exact model tag, including `:latest` when the tag is omitted.
- The ASR cache check validates nonempty JSON configuration and tokenizer files, readable weight files, and the tensors named in a shard index. Download progress reports completion after this check succeeds.
- Skipping a missing optional Ollama model disables polishing and translation and saves that choice with setup completion.
- Preferences retain edits across sections. A correction or snippet saved to an empty library is immediately available, and the hotword window refreshes terms learned after it opened.

### Spoken punctuation and correction rules

- Consecutive punctuation commands convert together: `open quote hello close quote period` produces `"hello".`.
- Opening/closing quotation marks and brackets can surround spoken content: `hello open parenthesis world close parenthesis period` produces `hello (world).`.
- Chinese commands support quotation marks, parentheses, square brackets, and book-title marks. `他说左引号你好右引号句号` produces `他说“你好”。`.
- Nested quotes and parentheses retain their order. Ordinary phrases describing punctuation remain unchanged when they do not form a punctuation command sequence.
- Correction replacements treat backslashes literally and apply longer matching terms first.

### Clipboard and saved data

- Delayed clipboard restoration checks whether the user has copied new content before reusing an earlier saved clipboard value. New copies survive repeated insertions and restoration delays.
- Configuration, custom dictionary, corrections, snippets, hotwords, and history validate stored JSON and field types. Invalid data raises an explicit error and leaves the original file intact.
- History records have unique identifiers. Text and outcome updates write atomically while holding the history lock. Readers and exports use independent snapshots.

### Installation and build checks

- The minimum system target is **macOS 14 on Apple Silicon**.
- The release DMG installs by dragging SpeakType into Applications. The application includes its Python runtime and dependencies.
- Both the standalone-app and DMG build paths check strict bundle signatures and execute runtime verification inside the embedded environment.
- Bundle checks inspect Apple Silicon Mach-O binaries, linked-library paths, minimum macOS requirements, app version metadata, and Python archives.
- Builds use ad hoc code signing. Build intermediates and complete logs are stored under `work/`.
- The English and Chinese README files introduce DMG installation, macOS permissions, dictation, history, and recovery before source-development instructions.

## 中文

### 听写历史与文本恢复

- 从菜单栏打开 **听写历史**，可以搜索原始转写、最终文本、应用名称、时间和插入结果。
- 选择记录后，可以查看完整的原始转写与最终文本，再使用各自的复制按钮。复制会保留换行和 Unicode 字符。
- 刷新列表时，只要原来选中的记录仍然可见，窗口就会继续选中这条记录。没有历史记录和没有搜索结果时，会显示不同说明。
- 历史支持导出 TXT、Markdown、CSV 和 JSON。**听写统计** 作为独立菜单项目保留。
- 开启历史记录后，普通听写会在本地润色前保存原始转写，并在插入前保存最终结果。润色或插入发生错误时，可以恢复已经保存的文本。
- 历史记录区分 **尚未确认**、**已插入**、**已发送（未验证）** 和 **插入失败**。已发送但未验证表示输入事件已经发送，目标应用提供的信息不足以确认插入结果。
- **复制最近听写** 可以复制最近一次可用结果。**再次插入最近听写** 会把结果插入当前聚焦的应用。关闭持久历史记录后，当前会话仍然保留最近一次结果。
- 普通听写、快捷短语展开和所选文本编辑，都会在尝试插入前保存已有的原始内容与最终文本。
- 旧记录缺少插入结果时，会显示为 **已发送（未验证）**。

### 安全撤销

- `撤销刚才`、`undo that` 和 `scratch that` 可以删除已验证的插入内容。执行时，输入框、完整正文和光标位置必须与插入完成时一致。
- 程序使用 UTF-16 位置保存光标与选区，可以正确选择包含 emoji 和其他 Unicode 字符的听写内容。
- 撤销通过辅助功能接口精确选择对应内容，再次检查目标后删除选区，并验证删除后的正文。
- 移动光标、选择其他内容、编辑正文、切换文档，或者目标无法提供可读取的辅助功能文本时，程序会保留当前正文。

### 语言、权限与模型准备

- 仅开启润色时，提示会要求保持输入语言，重试也会保留原来的语言要求。检查会拒绝明显的拉丁文字与中日韩文字转换，覆盖短英文输入。
- 设置向导与本地自检会读取真实麦克风授权，并检查录音、快捷键和文字插入需要的输入权限。
- Ollama 检查使用设置中的服务地址与完整模型标签；没有指定标签时使用 `:latest`。
- 语音模型缓存检查包含非空 JSON 配置、分词文件、可读取的权重，以及索引中列出的权重内容。完成检查后，下载进度才会显示完成。
- 跳过尚未安装的可选 Ollama 模型后，会关闭润色与翻译，并保存设置完成状态。
- 偏好设置在切换分区后保留修改。空词库首次保存的纠错与快捷短语立即生效；热词窗口刷新后，可以显示打开窗口之后学习到的词语。

### 口述标点与纠错

- 连续口述的标点可以一起转换。例如，`open quote hello close quote period` 会生成 `"hello".`。
- 引号和括号可以包含口述内容。例如，`hello open parenthesis world close parenthesis period` 会生成 `hello (world).`。
- 中文支持引号、圆括号、方括号和书名号。`他说左引号你好右引号句号` 会生成 `他说“你好”。`。
- 引号与括号嵌套时会保留正确顺序。普通句子中讨论标点名称的内容，在没有构成标点指令序列时保持原样。
- 纠错会按原样保留替换文本中的反斜杠，并优先处理较长的匹配词语。

### 剪贴板与保存文件

- 稍后恢复剪贴板时，程序会检查用户是否已经复制了新内容，再决定是否复用此前保存的剪贴板内容。连续插入和延迟恢复都会保留用户新复制的内容。
- 配置、自定义词典、纠错、快捷短语、热词和历史记录会验证 JSON 与字段类型。无效数据会明确报告错误，原文件得到保留。
- 每条历史记录都有唯一标识。更新文本和插入状态时，程序会持有历史记录锁，并通过原子写入保存文件。读取和导出使用独立的数据副本。

### 安装与构建检查

- 最低系统要求为 **macOS 14，Apple Silicon**。
- 打开发布的 DMG 后，把 SpeakType 拖动到应用程序文件夹即可安装。应用内置 Python 运行环境和依赖。
- 独立应用与 DMG 的构建流程都会严格检查应用包签名，并在内置环境中执行运行检查。
- 应用包检查包含 Apple Silicon 二进制文件、动态库路径、最低 macOS 要求、应用版本信息和 Python 归档文件。
- 构建使用 ad hoc 代码签名，中间文件和完整日志保存在 `work/`。
- 中英文 README 优先介绍 DMG 安装、系统权限、听写、历史与恢复操作，源码说明位于后部。
