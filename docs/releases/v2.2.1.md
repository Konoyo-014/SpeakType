# SpeakType v2.2.1 Release Notes

SpeakType v2.2.1 is a UI and interaction polish release for the adaptive-hotword era. The main goal is to make the new local learning system observable and controllable without requiring the user to open JSON files or infer state from logs.

The menubar now shows adaptive-hotword status as active and learned counts, and it can reveal the local hotword store directly. Preferences now includes a dedicated Adaptive Hotwords section for turning learning, context injection, and correction promotion on or off, as well as tuning the observation window, edit-stability delay, and maximum hotword context size per dictation.

The diagnostics window has been redesigned as a native checklist rather than a monospaced text block. It keeps the copyable plain-text report but shows summary counts, severity color, detail text, and repair actions in the window itself. Hotword readiness is now part of the diagnostics pass, so the app can report whether learning and context use are enabled and how many learned terms are active.

The recording overlay can now display a small contextual note when learned hotwords are being supplied to the current dictation. The dictionary window also behaves more predictably: removing snippets and corrections now follows the selected row instead of silently deleting the last item. Statistics now shows explicit empty-state rows when no app history or recent dictations exist.

Verification completed for this release includes the full Python test suite, source compile checks, diff whitespace checks, DMG verification, mounted-app version checks, mounted-app strict codesign verification, and a real macOS UI pass with Computer Use for Preferences, Diagnostics, Statistics, Dictionary, and the recording overlay.
