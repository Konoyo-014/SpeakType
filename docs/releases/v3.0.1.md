# SpeakType v3.0.1

2026-11-07

## 听写与编辑

主窗口使用深墨绿色导航侧栏、暖白色编辑区域和青绿色热词提示区域。听写、热词词典、历史记录与准备设置具有固定入口，明暗主题保持一致的颜色关系。正文使用原生文字编辑控件，支持选择、修改、复制、撤销和重做。原始转写可以展开查看，目标应用选择、润色、翻译与插入操作直接呈现。

麦克风、语音模型、语言模型、插入权限和快捷键状态集中显示，可以查看详情并打开准备设置。

录音、停止、取消、原生文字编辑、undo/redo、复制、目标应用选择、润色、翻译和快捷键继续通过实际原生控件工作。主窗口录音生成可以检查的结果，全局快捷键使用录音开始时记录的目标输入位置。

麦克风准备期间可以取消。设备超过八秒仍未开始采集时，窗口显示具体错误并继续响应操作；取消后可以立即重新开始。设备错误也会显示在准备状态中，后台权限检查继续保留这条设备提示。

## 热词词典

三列分别展示词语分类、可搜索的词语列表和词条详情。分类包含全部词语、已启用、学习候选、已停用与优先识别。列表可以按照优先识别、名称或使用次数排序，详情显示标准拼写、最多八种常见误识别写法、应用与场景范围、实际使用次数和最近使用日期。原有自定义词典中的词语也在这里管理。

“优先识别这个词语”让重要人名、项目名和专业术语优先进入识别提示。停用状态、应用范围和提示预算继续生效。词典显示指定应用与场景中的适用词语数量、入选数量和未入选词语，便于判断词库配置如何影响识别。

词典支持 JSON、CSV 和 TXT 导入。TXT 每行填写一个词语；CSV 至少包含 `term` 列，导出的 CSV 提供全部可用列。JSON 和 CSV 导出均保留词条状态、已批准的错误写法、应用范围、优先识别、使用次数与最近使用时间，程序检查完整文件后统一保存。TXT 和只有 `term` 列的 CSV 添加新词语，并保留已有词语的全部设置；JSON 和包含设置字段的 CSV 会更新相同标准拼写的条目。

“试试纠错效果”接收转写文字，使用与实际听写相同的原有纠错规则、热词规则和处理顺序，显示输出和逐条修改。应用与场景可以分别指定，便于检查范围。这个区域用于检查文字替换；录音效果通过新的听写结果检查。

未保存的词条草稿在当前应用运行期间保留。切换条目、刷新、关闭与重新打开词典继续保留草稿。退出应用前，可以返回词典保存，或者明确舍弃草稿。

选择最终文本中的术语并点击“记住这个词”，即可保存标准拼写和常见误识别。再次保存同一个词语会保留已有错误写法和范围。自动学习与历史保存分别由偏好设置控制。

## 识别与纠错

Qwen3-ASR 通过 `system_prompt` 参数接收 `Vocabulary: term1, term2.`。流式预览和最终识别使用相同的提示构造。默认每次最多使用 30 个词语，完整提示最多占用 800 个字符，包括前缀和分隔符。旧版自定义词典同样参与选择。

提示首先选择用户设置优先识别的适用词语，然后综合手动来源、应用与场景、真实使用次数和最近使用情况排列其他词语。一次成功保留的听写中，同一个词语重复出现只增加一次使用次数。统计使用明确纠错后的识别文字，记录当前应用与最近使用时间。重新打开历史、手动编辑文字，以及在保留识别结果之前取消操作，均保持计数不变。识别结果已经保留后，取消后续润色或翻译会保留这次使用记录。

明确的误识别写法在本地进行一次替换，处理完整适用词库。识别提示的数量限制独立于明确纠错范围。较长词组优先，输出保留用户指定的大小写，英文术语可以紧邻中文文字。保存时会报告相互冲突的错误写法，已有冲突规则保留原文；英文缩写和词语内部的子字符串得到保护。每条学习别名单独保存置信度和批准状态，新增的学习写法使用自己的分数。用户明确保存或启用词条时，当前写法会得到批准。暂停词条同时停止该词条的识别提示和纠错；后续学习保留暂停状态。删除后，自动学习会继续忽略该词语；明确手动添加或导入可以恢复使用。

新增、编辑、改名、启停、删除、学习和使用统计都在文件成功保存后更新当前词库。保存失败会保留原有内容，便于处理错误后重新操作。

历史记录保留原始识别、选中的识别提示、最终文本和明确的纠错记录。编辑最终文本或重新打开记录时，这些信息继续保留。完整历史提供热词详情，并能把所选记录打开到听写编辑区。所有模型推理、原生控件与并发取消验证分别记录检查范围。

## 模型下载

下载失败时，应用根据真实异常显示连接超时、等待数据超时、DNS 解析失败、证书验证失败或具体 HTTP 状态，并提供对应的处理和重试建议。详细原因继续可见，下载程序以失败状态结束。已经下载的缓存保留，重新下载成功并通过模型文件检查后才会显示完成。

## 已验证的范围

`scripts/validate_hotword_personalization.py --asr` 使用真实 Qwen3-ASR 和 macOS 合成语音，验证优先识别、提示数量和长度限制、普通中英文句子及静音。在包含 62 个词语的词库中，每次选择 30 个提示词；同一条含两个专名的录音，优先识别前原始转写符合标准拼写的词语为 0 个，优先识别后为 1 个，明确纠错后为 2 个。这些结果描述该组输入，准确率统计需要不同说话人和真实录音环境的数据。

同一脚本验证 10,020 个词语中的末尾词条仍然参与明确纠错、重复纠错复用编译结果、真实文件持久保存、24 次并发使用计数，以及实际权限拒写时的内容一致性。

`scripts/validate_v301_integration.py` 验证实际识别进入应用与历史后增加使用次数，关闭热词开关后保持计数，编辑和重开历史不重复计数，并在真实推理等待期间取消后拒绝保存旧结果和使用记录。

`scripts/validate_hotword_persistence.py` 验证词条与纠错规则的实际拒写处理、原有词典管理、逐条学习写法批准、删除后学习处理和完整文件验证。

`scripts/validate_vocabulary_workspace.py` 验证原生 AppKit 词语控件、实际词条操作、草稿、关闭与重开窗口、中英文及明暗外观。

`scripts/validate_vocabulary_priority_ui.py` 验证优先识别控件、真实使用次数排序、提示选择、CSV/JSON 完整导出与导入、TXT 和单列 CSV 保留已有配置，以及无效 CSV 的整体拒绝。10,020 个词语的 JSON 和 CSV 备份分别完成导出、重新导入与全字段比较，保留状态、优先识别和使用记录。

`scripts/validate_desktop_flow.py` 验证实际麦克风采集、扬声器语音经麦克风进入 Qwen3-ASR、TextEdit 插入、目标内容改变后的保护，以及原生编辑、取消、润色与翻译。

`scripts/validate_download_errors.py` 验证实际关闭端口、DNS 解析、读取超时、HTTP 404/501 和证书握手失败，确认下载程序在完整 HTTP 失败后以非零状态退出并保留错误详情。

调研来源、用户痛点与验收条件见 [产品调研文档](../product/v3.0.1-research.md)。

## 安装

需要搭载 Apple Silicon 的 Mac，系统为 macOS 14 或更高版本。下载 `SpeakType-3.0.1.dmg` 并把 SpeakType 拖动到 Applications。应用包含 Python 与运行依赖，语音模型和可选的 Ollama 模型通过准备设置管理。默认语音识别在本机运行；如果自行配置远程 Ollama 地址，文字处理请求会发送到所选地址。

## English

SpeakType 3.0.1 provides an ink-green navigation sidebar, a warm light editor, a teal vocabulary strip, and coordinated light/dark appearances. Native editing, undo/redo, original transcription, recording, copy, and insertion remain directly accessible. The three-column vocabulary workspace supports prioritized terms, actual usage counts, recent-use dates, app/context limits, learned candidates, search and sorting. Import JSON, CSV, or one-word-per-line TXT; export JSON or CSV with state, approved aliases, priority, scope, and usage history preserved. Unsaved vocabulary drafts survive navigation and closing the window during the current session.

Qwen3-ASR receives bounded `Vocabulary` prompts through its actual `system_prompt` input, shared by preview and final recognition. The default allows 30 terms within an 800-character prompt. Explicit priority, application relevance, and actual usage guide selection. The interface exposes selected/applicable counts and omitted terms. Explicit aliases apply across the eligible vocabulary independently of the recognition-hint budget, with exact casing, longer-phrase priority, boundary protection, and a single replacement pass. Paused entries stay paused when learning arrives, and deleted terms stay excluded from automatic learning.

Actual vocabulary usage is counted once per successfully retained dictation. Results cancelled before retention do not increase usage; reopening history and manual edits leave usage unchanged. Cancelling later polishing or translation preserves usage already recorded for the retained transcription. History retains original recognition, selected hints, final text, and applied changes. Model-download failures expose their network or service cause and keep a failed operation in a failed state until a retry succeeds.

Validation uses actual files, native AppKit controls, real concurrent operations, local network failures, and the Qwen3-ASR model. Audio comparisons use macOS speech synthesis and establish behavior on those specific inputs; they do not estimate accuracy across speakers or recording environments.
