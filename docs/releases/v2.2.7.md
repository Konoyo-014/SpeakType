# SpeakType v2.2.7 Release Notes

SpeakType v2.2.7 improves the adaptive-hotword status window. Real Computer Use testing with long learned terms, long aliases, and long application identifiers showed that fixed-height rows could clip the second line of row detail, hiding context such as `com.microsoft.VSCode`. The window now sizes each hotword row from the displayed content, keeps the learned term as the primary readable object, and wraps aliases and application context without cutting them off.

The Copy Context action now has visible feedback in the window. After copying, the footer reports how many active hotwords were copied, while the copied context itself still includes only active terms and excludes candidate terms.

Verification completed for this release includes source compile checks, targeted hotword-window tests for row sizing and active-context copy behavior, real Computer Use checks for the native adaptive-hotword window with long rows and active/candidate terms, direct clipboard smoke testing with restoration of the original clipboard content, full Python test suite, diff whitespace checks, clean temporary DMG build, mounted-app metadata checks, bundled import version check, and mounted-app strict codesign verification.
