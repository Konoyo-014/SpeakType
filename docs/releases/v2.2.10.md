# SpeakType v2.2.10 Release Notes

SpeakType v2.2.10 improves the Local Diagnostics window. Real testing showed that the window still carried English-only `OK / WARN / FAIL` counters inside the Chinese interface, and Copy Report had no visible confirmation after writing to the pasteboard.

The diagnostics summary now uses localized count labels. In Chinese it reads as normal, attention, and failure counts, matching the rest of the native UI. Refresh also has an explicit in-place running state: the Refresh button becomes disabled and changes to a checking label while the background diagnostics worker runs, and Copy Report is disabled until a fresh report is available.

Copy Report now confirms success directly on the button by changing its label to Copied. Starting another refresh resets the button, so the visible state always reflects the latest action instead of leaving the user to infer whether the pasteboard operation worked.

This release also namespaces the native flipped-view classes used by Local Diagnostics and Adaptive Hotwords. Full-suite testing caught that the previous generic `_FlippedView` name could collide in PyObjC when both modules loaded in the same process.

Verification completed for this release includes source compile checks, targeted diagnostics-window tests for localized summary counts, targeted diagnostics/hotword import collision coverage through pytest collection, real Computer Use checks for localized summary rendering, copy confirmation, disabled running state, and post-refresh recovery, full Python test suite, diff whitespace checks, clean temporary DMG build, mounted-app metadata checks, bundled import version check, and mounted-app strict codesign verification.
