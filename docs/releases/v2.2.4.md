# SpeakType v2.2.4 Release Notes

SpeakType v2.2.4 is a native-window interaction polish release. The main fix is the statistics window: real Computer Use testing with a fuller history showed that the previous fixed-height layout pushed the Recent Dictations section below the visible window. The new version uses a fixed header, a scrollable content region, metric tiles, native activity bars, app-frequency bars, wrapped recent-dictation rows, and a fixed footer with Export History and Close actions.

The dictionary window also receives spacing hardening. The selected-row delete buttons for snippets and corrections now sit below their lists with stable spacing, and the scrollable document is taller so the correction section is not cramped against the fixed footer.

Verification completed for this release includes source compile checks, targeted statistics/dictionary/diagnostics/hotword tests, real macOS Computer Use checks for Statistics before and after the fix, Dictionary spacing and bottom scrolling, Settings, Diagnostics copy-report behavior, full Python test suite, diff whitespace checks, clean temporary DMG build, mounted-app metadata checks, bundled import version check, and mounted-app strict codesign verification.
