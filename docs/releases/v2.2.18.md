# SpeakType v2.2.18

Released: 2026-05-08

## Focus

This release makes the Adaptive Hotwords window's copy action truthful and non-destructive when there are no active learned hotwords.

## Changes

- Copy Context now shows an explicit empty-state message when there are no active hotwords.
- The clipboard is no longer cleared when there is no hotword context to copy.
- Non-empty Copy Context still copies the active learned hotword terms in priority order.
