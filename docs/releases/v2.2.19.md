# SpeakType v2.2.19

Released: 2026-05-08

## Focus

This release makes the Adaptive Hotwords window refresh behave like a clean state reload instead of leaving stale copy feedback behind.

## Changes

- Refresh clears Copy Context feedback from prior actions.
- Empty refreshed hotword lists reset the scroll document height, so old tall-list layout state does not leave blank scrollable space.
- Copy Context behavior from v2.2.18 remains unchanged: empty active context does not touch the clipboard.
