# SpeakType v2.2.5 Release Notes

SpeakType v2.2.5 tightens the first-launch setup wizard. Real Computer Use testing found that the Ollama step could display both `ollama serve` and `ollama pull ...` at the same time, but both Copy Command buttons reused the last command stored by the page. The fixed wizard binds each copy button to its own command, so the service-start button copies `ollama serve` and the model-pull button copies the configured pull command.

The wizard now also shows a step counter and progress bar on every page. This keeps the initial setup flow oriented without adding a sidebar or extra controls, and the window is slightly taller so the LLM setup page keeps stable spacing with long local-model commands.

Verification completed for this release includes source compile checks, targeted setup/statistics/dictionary/hotword tests, real macOS Computer Use checks across the welcome, permissions, ASR, LLM, and completion wizard pages, clipboard verification for both command buttons, full Python test suite, diff whitespace checks, clean temporary DMG build, mounted-app metadata checks, bundled import version check, and mounted-app strict codesign verification.
