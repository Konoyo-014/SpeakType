# SpeakType v2.2.8 Release Notes

SpeakType v2.2.8 rebuilds Preferences for the V2.2 adaptive-hotword era. The old preferences window was a single long scrolling form, which made the new hotword controls hard to find and exposed the entire control tree to macOS Accessibility at once. Real testing also showed that this could make external UI inspection sluggish. Preferences is now split into native sections: General, AI Models, Features, Adaptive Hotwords, and System.

Adaptive Hotword settings are now directly reachable from the left navigation rail. The learning toggle, recognition-context toggle, correction-promotion toggle, observation window, edit-stability delay, and maximum hotwords per dictation all fit in one view without scrolling.

The window preserves edits while switching sections. Numeric hotword settings are clamped when the user leaves and re-enters the section, so a value like `999` for maximum context terms becomes the configured upper bound of `80` before saving.

Verification completed for this release includes source compile checks, targeted settings-window tests for section ownership and value reading, real Computer Use checks for every Preferences section, real hotword numeric clamp testing across section switches, save-callback verification, full Python test suite, diff whitespace checks, clean temporary DMG build, mounted-app metadata checks, bundled import version check, and mounted-app strict codesign verification.
