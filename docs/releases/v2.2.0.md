# SpeakType v2.2.0

Released: 2026-05-08

Status: Official public release

## English

SpeakType v2.2.0 is the official V2.2 release. It consolidates the local adaptive-hotword development cycle into one public version: automatic post-edit learning, local model analysis, ASR context injection, native hotword visibility, first-run setup hardening, local diagnostics, and the full round of macOS UI interaction polish.

### Adaptive Hotwords

- SpeakType now learns hotwords automatically from the edits users make immediately after SpeakType inserts dictated text.
- The observer watches only the short-lived inserted span in the same focused input field. It ignores unrelated typing, append-only text, app switches, unreadable inputs, password-like targets, and unchanged spans.
- The local Ollama model analyzes post-insert edits and returns strict JSON describing reusable terminology, acronyms, proper nouns, code identifiers, spelling, capitalization, and hyphenation preferences.
- When Ollama is unavailable, SpeakType still has a conservative fallback for obvious technical terms.
- Learned terms are stored locally in `~/.speaktype/hotwords.json`; they are not uploaded, synced, or used for telemetry.
- Hotwords are contextual hints, not unconditional replacements. SpeakType selects a compact active context by app, scene, language, confidence, observation count, and recency.
- Active hotwords are passed into Qwen3-ASR when the installed `mlx-audio` path supports a `context` argument, and the same terms are supplied to local polish and translation prompts so exact spellings are preserved when those terms are actually present.
- High-confidence wrong-to-right pairs can be promoted into the existing correction store, keeping deterministic corrections separate from ASR biasing.

### Native Visibility and Controls

- Preferences now has a dedicated Adaptive Hotwords section with toggles for learning, ASR/polish context, correction promotion, observation timing, stability delay, and maximum context size.
- The menubar opens a native Adaptive Hotwords window showing active and candidate terms, confidence, observation count, aliases, last update time, and app context.
- Copy Context copies only active learned terms and gives visible feedback. Empty context no longer clears the user's clipboard.
- Reveal File opens the hotword file or configuration folder and reports the action result in the window.
- Repeated menubar actions now reuse already-visible Settings, Dictionary & Snippets, Statistics, Local Diagnostics, and Adaptive Hotwords windows instead of creating duplicates.

### Local Diagnostics and Setup

- Local Diagnostics is now a native checklist with localized summaries, severity state, wrapped details, repair actions, refresh progress, and copy-report confirmation.
- Diagnostics includes hotword readiness, macOS input permissions, microphone discovery, Qwen3-ASR cache/load state, Ollama installation, Ollama service reachability, configured model availability, and focused-input writability.
- The first-launch setup wizard now has a progress indicator, localized readiness labels, exact command-copy feedback, explicit ASR model download action, readable retryable error states, and Hugging Face progress-wrapper compatibility for newer `huggingface_hub` versions.
- ASR model download failures now render as full localized states instead of raw Python exceptions or clipped one-line errors.

### Editing, Insertion, and macOS Reliability

- Focused input capture now falls back from the system-wide Accessibility focused element to the frontmost application's `AXFocusedUIElement`, improving insertion verification and post-insert edit observation in apps such as TextEdit.
- The recording HUD now uses a native read-only multiline text view, so long CJK text and mixed technical terms wrap instead of being clipped.
- HUD width responds to the visible screen frame, keeping the overlay inside narrow displays and split-screen layouts.
- Streaming preview can receive the same active hotword context as final transcription while remaining display-only.
- Permission reset handling includes a timeout so local TCC reset attempts cannot hang indefinitely.

### Native Window and Interaction Polish

- Preferences was rebuilt into native sections: General, AI Models, Features, Adaptive Hotwords, and System.
- Dictionary & Snippets was rebuilt into native sections for Custom Dictionary, Snippets, and Corrections, with live counts, fixed footer feedback, selected-row deletion, long-text layouts, and a two-step dirty-close guard.
- Statistics was rebuilt as a scrollable native dashboard with metric tiles, activity bars, app-frequency bars, wrapped recent-dictation rows, localized duration units, localized weekday labels, and fixed footer actions.
- Local Diagnostics and Adaptive Hotwords reset stale scroll document heights when returning to empty or running states.
- Chinese UI polish now covers hotkey names, About text, setup wizard labels, ASR download status, diagnostics summaries, statistics duration units, weekday labels, and copy confirmations.

## 中文

SpeakType v2.2.0 是 V2.2 的正式公开版本。这个版本把本地自适应热词开发周期合并成一个正式 release：自动从修改中学习热词、本地模型分析、ASR 上下文注入、原生热词可视化、首次启动向导加固、本地自检，以及完整一轮 macOS 原生界面与交互打磨。

### 自适应热词

- SpeakType 现在会从用户对“刚由 SpeakType 插入的听写文本”的即时修改中自动学习热词。
- 观察器只观察同一个聚焦输入框里那一小段刚插入的文本；无关输入、单纯追加、应用切换、不可读取输入框、类似密码的目标和未发生变化的文本都会被忽略。
- 本地 Ollama 模型会分析插入后的修改，并返回严格 JSON，提取可复用术语、缩写、专名、代码标识符、拼写、大小写和连字符偏好。
- 当 Ollama 不可用时，SpeakType 仍会对明显技术术语使用保守 fallback 学习。
- 学到的热词只保存在本机 `~/.speaktype/hotwords.json`，不会上传、同步，也不会用于遥测。
- 热词是上下文提示，不是无条件替换。SpeakType 会按应用、场景、语言、置信度、观察次数和近期程度选择一小组 active context。
- 当当前安装的 `mlx-audio` 支持 `context` 参数时，active hotwords 会传入 Qwen3-ASR；同一组术语也会传给本地润色和翻译提示，让模型在确实提到这些术语时保留精确拼写。
- 高置信度的“错法 -> 正确写法”可以进入现有纠错库，从而把确定性纠错和 ASR 上下文偏置分开。

### 原生可视化与控制

- 偏好设置新增 Adaptive Hotwords 独立分区，可以控制学习开关、ASR/润色上下文、纠错提升、观察窗口、稳定等待时间和单次上下文数量上限。
- 菜单栏现在可以打开原生 Adaptive Hotwords 窗口，展示 active/candidate 状态、置信度、观察次数、别名、最近更新时间和应用上下文。
- Copy Context 只复制 active learned terms，并在窗口内给出反馈；没有 active context 时不会清空用户剪贴板。
- Reveal File 会打开热词文件或配置文件夹，并在窗口内说明实际执行结果。
- 重复点击菜单栏入口时，Settings、Dictionary & Snippets、Statistics、Local Diagnostics 和 Adaptive Hotwords 会复用已打开窗口，不再生成重复窗口。

### 本地自检与首次启动

- Local Diagnostics 改为原生 checklist，包含本地化摘要、状态等级、自动换行详情、修复动作、刷新进度和 Copy Report 确认。
- 自检现在覆盖热词 readiness、macOS 输入权限、麦克风发现、Qwen3-ASR 缓存/加载状态、Ollama 安装、本地 Ollama 服务、配置模型可用性，以及当前聚焦输入目标是否可写。
- 首次启动向导新增进度条、本地化 readiness 标签、精确命令复制反馈、显式 ASR 模型下载按钮、可读的失败重试状态，并兼容新版 `huggingface_hub` 传入的下载进度参数。
- ASR 模型下载失败现在会显示完整本地化状态，不再暴露原始 Python 异常，也不会把长错误压成一行截断。

### 编辑、插入与 macOS 可靠性

- 聚焦输入捕获现在会从系统级 Accessibility focused element fallback 到前台应用自己的 `AXFocusedUIElement`，这提升了 TextEdit 等应用里的插入验证和插入后修改观察稳定性。
- 录音 HUD 改用原生只读多行文本视图，长中文和混合技术术语会正常换行，不再被右侧裁切。
- HUD 宽度会根据当前可见屏幕范围响应，窄屏和分屏下不会越界。
- 流式预览可以接收与最终转写相同的 active hotword context，但仍保持只展示、不插入的行为边界。
- 权限重置增加超时保护，本地 TCC reset 不会无限挂住。

### 原生窗口与交互打磨

- Preferences 重建为原生分区窗口：General、AI Models、Features、Adaptive Hotwords 和 System。
- Dictionary & Snippets 重建为 Custom Dictionary、Snippets、Corrections 三个分区，带实时计数、固定底部反馈、选中行删除、长文本布局和两步 dirty-close 防护。
- Statistics 重建为可滚动原生 dashboard，包含指标卡片、活动柱状条、应用频率条、自动换行的近期听写记录、本地化时长单位、本地化星期标签和固定底部操作。
- Local Diagnostics 和 Adaptive Hotwords 在回到空状态或运行状态时会重置旧的滚动文档高度，避免残留空白滚动区。
- 中文 UI 继续补齐快捷键名称、About 文案、首次启动标签、ASR 下载状态、自检摘要、统计时长单位、星期标签和复制确认。
