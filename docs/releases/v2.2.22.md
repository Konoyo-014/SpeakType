# SpeakType v2.2.22

Released: 2026-05-08

## Focus

This release prevents repeated menubar actions from creating duplicate utility windows.

## Changes

- The app now reuses already-visible Settings, Dictionary & Snippets, Statistics, Local Diagnostics, and Adaptive Hotwords controllers.
- Repeated menu clicks raise the existing visible window, preserving in-progress edits and avoiding desktop clutter.
- Closed or hidden windows are still rebuilt normally the next time the user opens them.
