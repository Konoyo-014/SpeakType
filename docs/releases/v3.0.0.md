# SpeakType v3.0.0

## Install and prepare

Requires **an Apple Silicon Mac with macOS 14 or later**. Download `SpeakType-3.0.0.dmg`, open it, and drag SpeakType into Applications. The application includes Python and its runtime dependencies.

The native main window opens at launch. Its readiness cards show microphone permission, speech recognition, the local language model, text insertion, and the global shortcut. Open **Setup** to prepare everything in one window:

1. Open the corresponding Microphone, Accessibility, and Input Monitoring pages, allow SpeakType, and refresh. Restart the app when macOS requests it.
2. Download the default `mlx-community/Qwen3-ASR-1.7B-8bit` speech model, about **2.47 GB**. Completion requires readable configuration, tokenizer, and complete weight files.
3. Choose **Use dictation only**, or install/start Ollama and select an installed model. The configured default is `huihui_ai/qwen3.5-abliterated:9b-Claude`, about **6.59 GB**.
4. Use **Download model** for a missing language model. Actual bytes and percentage are shown. Cancelling preserves the official cache for retry; returning to the main window keeps the download running.
5. Use **Try dictation** to start recording in the main window.

The setup window offers the official Ollama installation page and an update action when the service requires a newer version. **Error details…** opens the complete, selectable error with scrolling and a copy button. A damaged ASR cache offers **Redownload model**, which explicitly downloads and verifies the complete model through the official Hugging Face client. Language changes and closing/reopening the window preserve active downloads.

## Record, edit, and deliver

- **Start dictation** and **Stop recording** show elapsed time, microphone level, live recognition, original transcription, and final text in the main window.
- Final text is editable. **Copy**, **Polish again**, and **Translate** work on that text; translation has an explicit target-language selector.
- Select the intended input field in another app, return to SpeakType, choose the destination app, and click **Insert into…**. The application checks the selected process and available target information before sending text.
- Main-window recording prepares text for review. The global shortcut supports direct insertion and captures the destination when recording starts. Right Command is the default shortcut; push-to-talk and toggle modes are configurable.
- Cancel recording, recognition, polishing, or translation while keeping available text. Results from cancelled or superseded operations cannot overwrite the current result or continue to insertion.
- Manual edits update the same history record and mark the text as saved for insertion. Recent records remain accessible in the main window; the full history provides search, copying, and export.
- Main-window shortcuts include `⌘R` for recording, `⌘↩` for insertion, `⇧⌘C` for copying, `⇧⌘P` for polishing, `⇧⌘T` for translation, and `Esc` for cancellation.

## History, editing, and local data

- History retains original transcription before model processing and final text before insertion. It distinguishes saved, processing, verified insertion, sent-but-unverified, failed, and cancelled results.
- Search covers original/final text, application, time, and result. Separate copy buttons preserve full Unicode text; export supports TXT, Markdown, CSV, and JSON.
- The latest result remains available during the session when persistent history is disabled. A failed insertion can be copied or inserted again after selecting a suitable target.
- Voice undo removes the exact verified insertion only while its field, full text, and UTF-16 cursor range still match. Cursor movement, selection changes, document edits, and document switching preserve current text.
- Spoken English and Chinese punctuation supports adjacent quotation marks, brackets, and closing punctuation, including nested content.
- Polishing preserves the input language. Language retries retain the requested language; translation remains an explicit operation.
- Clipboard restoration preserves newer user copies. Corrections keep literal replacement text and apply longer matching terms first.
- Configuration, dictionary, snippets, corrections, hotwords, and history validate stored JSON and field types. Invalid files remain intact with a concrete error.
- Preferences, dictionary, statistics, hotwords, diagnostics, history, and help are available through native controls. Vocabulary saved to an empty library is immediately available, and hotword refresh reads the active store.

## 安装与准备

需要 **macOS 14 或更高版本，以及搭载 Apple Silicon 的 Mac**。下载并打开 `SpeakType-3.0.0.dmg`，把 SpeakType 拖动到应用程序文件夹。应用已经包含 Python 和运行依赖。

启动后会显示原生主窗口。状态卡片分别显示麦克风、语音识别、本地语言模型、文字插入和全局快捷键。点击 **准备设置**，在同一个窗口完成以下操作：

1. 打开对应的麦克风、辅助功能和输入监控页面，允许 SpeakType 后刷新状态。系统要求重新启动时，重新启动应用。
2. 下载默认语音模型 `mlx-community/Qwen3-ASR-1.7B-8bit`，约 **2.47 GB**。配置、分词文件和完整权重通过检查后，才会显示完成。
3. 选择 **仅使用语音识别**，或者安装和启动 Ollama，再选择已安装的模型。默认语言模型为 `huihui_ai/qwen3.5-abliterated:9b-Claude`，约 **6.59 GB**。
4. 缺少语言模型时，点击 **下载模型**。窗口显示真实字节数和百分比。取消操作会保留官方缓存供重试；返回主窗口后，下载继续进行。
5. 点击 **试用录音**，在主窗口开始录音。

准备窗口提供 Ollama 官方安装页面；服务要求更新版本时，会出现更新按钮。**错误详情…** 会打开可以滚动、选择和复制完整错误内容的窗口。语音缓存损坏时，**重新下载完整模型** 使用官方 Hugging Face 工具重新下载并验证文件。切换界面语言，以及关闭和重新打开窗口，都会保留正在进行的下载。

## 录音、编辑与发送

- 主窗口的 **开始听写** 和 **停止录音** 会显示录音时长、麦克风音量、实时识别、原始转写与最终文本。
- 最终文本可以编辑。**复制**、**重新润色** 和 **翻译** 使用当前文本，翻译提供明确的目标语言选择。
- 点击其他应用中的目标输入框，返回 SpeakType，选择目标应用后点击 **插入到…**。应用会在发送之前检查所选进程和可获得的输入框信息。
- 主窗口录音生成可以检查的结果。全局快捷键用于直接插入，并在录音开始时记录目标应用。默认快捷键为右 Command，可以设置按住说话或按键切换。
- 录音、识别、润色和翻译期间可以取消，已有文本继续保留。已取消或已被新操作替代的任务，其后续结果不会覆盖当前结果或继续插入。
- 手动编辑更新原来的历史记录，并显示为待插入。主窗口可以选择最近记录，完整历史支持搜索、复制和导出。
- 主窗口支持 `⌘R` 录音、`⌘↩` 插入、`⇧⌘C` 复制、`⇧⌘P` 润色、`⇧⌘T` 翻译，以及 `Esc` 取消。

## 历史、编辑与本地数据

- 历史在模型处理之前保留原始转写，在插入之前保存最终文本，并区分已保存、正在处理、已验证插入、已发送未验证、失败和已取消。
- 可以按原始转写、最终文本、应用、时间和结果搜索。复制保留完整 Unicode 文本，导出支持 TXT、Markdown、CSV 和 JSON。
- 关闭持久历史后，当前会话仍保留最近结果。插入失败时，可以复制结果，或者重新选择目标后再次插入。
- 语音撤销仅在输入框、完整正文和 UTF-16 光标位置保持一致时，精确删除已经验证的插入内容。移动光标、改变选区、修改正文或切换文档后，当前文字会保留。
- 中英文口述标点支持连续引号、括号和结尾标点，也支持嵌套内容。
- 润色保持输入语言，重试保留原来的语言要求。翻译由明确的操作触发。
- 剪贴板恢复保留用户新复制的内容。纠错按原样保留替换文本，并优先匹配较长的词语。
- 配置、词典、快捷短语、纠错、热词和历史会验证 JSON 与字段类型。无效文件得到保留，同时报告具体错误。
- 原生控件提供偏好设置、词典、统计、热词、自检、历史与帮助。空词库首次保存的词语立即生效，热词刷新读取应用正在使用的数据。

## Build and runtime

The app targets Apple Silicon and macOS 14. Its Python 3.10 runtime and pinned dependencies are included in the application. Builds use ad hoc signing, strict signature verification, Mach-O dependency/deployment checks, source-content comparison, and actual embedded-runtime imports, WAV round trips, MLX computation, and Qwen3-ASR feature extraction. The ASR download helper runs through its own native app entry point. Complete build logs and intermediate files are stored under `work/`.

应用面向 Apple Silicon 和 macOS 14，包含 Python 3.10 与固定版本的运行依赖。构建会执行 ad hoc 签名、严格签名验证、二进制依赖与最低系统检查、源码内容核对，以及内置环境的真实导入、WAV 编解码、MLX 运算和 Qwen3-ASR 特征提取。语音下载程序通过独立的应用原生入口运行。完整构建日志和中间文件保存在 `work/`。
