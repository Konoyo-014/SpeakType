# SpeakType v2.2.17

Released: 2026-05-08

## Focus

This release makes the Dictionary & Snippets editor safer by preventing accidental loss of unsaved vocabulary, snippet, and correction edits.

## Changes

- The Close button now requires a second close action before discarding unsaved dictionary edits.
- The titlebar close control uses the same guard, so native window closing and the footer Close button behave consistently.
- Any later edit resets the discard confirmation, so users do not accidentally keep an old confirmation armed after changing more content.
