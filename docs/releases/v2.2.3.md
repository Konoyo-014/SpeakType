# SpeakType v2.2.3 Release Notes

SpeakType v2.2.3 continues the adaptive-hotword UI work by turning the menubar hotword entry into a native read-only status window. The user can now inspect what SpeakType has learned, see which terms are active versus still candidates, and copy the active context without opening `~/.speaktype/hotwords.json`.

The window is intentionally not a manual hotword editor. Adaptive hotwords are still learned from post-insert corrections and reinforced locally. The release makes that local learning visible through status, confidence, observation count, last update date, aliases, and app context while keeping the primary workflow automatic.

Real macOS Computer Use testing found that the first row layout could truncate right-side metadata. The final window uses multi-line rows so status, confidence, observations, date, aliases, and app context remain readable inside the native panel. Computer Use also verified the Copy Context action and the Reveal File action.

Verification completed for this release includes source compile checks, targeted hotword/diagnostics/dictionary/app-recording tests, real native-window interaction via Computer Use, full Python test suite, diff whitespace checks, clean temporary DMG build, mounted-app metadata checks, bundled import version check, and mounted-app strict codesign verification.
