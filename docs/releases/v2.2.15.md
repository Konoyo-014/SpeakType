# SpeakType v2.2.15

Released: 2026-05-08

## Focus

This release improves the setup wizard's retryable ASR download failure state.

## Changes

- Replaced the one-line ASR download failure label with a wrapped, variable-height status label.
- Long network, Hugging Face, model-not-found, or downloader compatibility errors now remain visible in the setup wizard.
- The explanatory hint and action buttons stay anchored below the expanded status text, so the user can still retry or download later without layout overlap.
- The failed-download state now removes the previous progress bar, avoiding a misleading blue progress indicator after an error has already occurred.
