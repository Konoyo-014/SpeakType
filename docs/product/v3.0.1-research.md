# SpeakType v3.0.1 产品依据与验收

调研日期：2026-11-07。产品对象是 macOS 上使用人名、项目名称、中英混合术语和专业词语进行日常听写的用户。

## 官方产品资料

| 来源 | 已核实的行为 | SpeakType 的设计要求 |
|---|---|---|
| [Superwhisper：Vocabulary](https://superwhisper.com/docs/get-started/interface-vocabulary) | 词语作为识别提示；明确替换在转写后执行；过多提示会影响识别；提供 CSV 导入。 | 限制单次识别提示长度，完整保存明确纠错规则，并支持常见文件格式导入。 |
| [Wispr Flow：Teach Flow your words](https://docs.wisprflow.ai/articles/4052411709-Teach-Flow-your-words-with-the-dictionary) | 词典保存专名和纠错；自动学习由设置控制；支持导入、检索与编辑；删除后自动学习继续忽略该词语。 | 用户能够明确管理学习结果、停用词语和保留删除意图；每次文件导入完整检查后统一保存。 |
| [Aqua Voice：Dictionary](https://aquavoice.com/guide/dictionary) | 字典面向人名、医学术语、内部缩写与自创名称；添加入口直接接受标准拼写。 | 新增词语只要求标准拼写，其余误识别写法、优先识别和应用范围由用户按需设置。 |
| [Wispr Flow：产品更新](https://wisprflow.ai/whats-new) | 词典提供重要词语标星、使用频次排序；桌面支持明暗与系统外观。 | 用户能够主动指定优先词语；词语使用记录能够影响选择并在界面中查看；明暗界面都需要检查。 |

## 用户反馈与问题

[Wispr Flow 的一位用户](https://www.reddit.com/r/WisprFlow/comments/1v7ve9m/wispr_flow_doesnt_learn_from_inapp_text/)描述了在 Thunderbird 和 Word 中反复修正专业词语，却无法判断应用是否学会的情况。这支持显示学习候选、实际使用次数，以及从最终文本直接保存词语的要求。该帖子是个体反馈，不能用于估计问题发生比例。

[Superwhisper 的词库更新讨论](https://www.reddit.com/r/superwhisper/comments/1tlinzd/dont_miss_this_in_the_latest_release/)包含用户对 CSV 批量维护的需求，也包含听写延迟和输出偏离原句的投诉。这支持减少逐个录入词语的工作，以及分别检查真实识别、明确纠错和文字编辑。讨论中的体验差异只作为场景依据。

本次用户明确提出热词识别需要实质改进、前端需要经过调研和设计。验收因此同时检查识别结果、词库管理和真实原生界面。

## 产品行为与验收条件

| 用户遇到的问题 | 产品行为 | 可以复核的验收条件 |
|---|---|---|
| 重要专名被其他词语挤出提示 | 用户设置优先识别；应用结合实际使用与当前应用选择提示词 | 在超过 30 个适用词语的词库中，优先词语进入提示；停用和应用范围仍然生效；完整提示长度符合预算。 |
| 保存词语后不了解是否参与识别 | 词典显示入选/适用数量、提示词和遗漏词语；主窗口保留实际识别提示 | 同一个范围下，界面显示的提示与 `active_context` 的返回值一致；超出数量或长度的词语可查看。 |
| 词语反复出现却没有影响后续选择 | 统计明确纠错后的实际识别结果，一次成功保留的听写对每个词语计数一次 | 重复词语只增加一次；原始误识别经明确纠错得到的标准词语计数；关闭总开关、保留结果之前取消、重开历史和手动编辑不增加次数；取消后续润色或翻译保留已记录的使用次数。 |
| 词库较大时明确纠错遗漏条目 | 完整适用词库参与明确纠错 | 10,020 个词语中的末尾规则可匹配；识别提示继续遵守数量与长度上限。 |
| 添加大量术语需要逐个输入 | 导入 TXT、CSV、JSON，导出 CSV、JSON | TXT 每行一个词语；TXT 和单列 CSV 添加新词语并保留已有配置；CSV 使用标准库读写；完整导出后再导入保留状态、范围、批准写法、优先识别和使用记录；无效文件整体拒绝。 |
| 学习结果需要用户检查和控制 | 学习候选单独展示，暂停与删除意图保留 | 学习不能重新启用暂停词语；删除后自动学习忽略该词语；用户手动添加可以恢复使用。 |
| 文字操作难以发现，颜色与布局缺少一致性 | 深墨绿导航、暖白编辑、青绿热词提示；词库使用分类/列表/详情三列 | 原生编辑、撤销、复制与插入可操作；中英文、明暗外观、关闭与重开保持有效；可见内容不重叠。 |
| 下载失败后用户无法处理 | 显示具体网络原因、错误详情与重试建议 | 真实连接拒绝、DNS、超时、HTTP 和证书失败有对应消息；worker 以失败状态结束；缓存得到保留。 |

## 构建与发布检查

已验证 `work/release-venv/bin/python` 的 Python 3.10 运行环境、依赖完整性和 macOS 最低部署版本。构建通过 `SPEAKTYPE_PYTHON` 指定该解释器，应用包含运行依赖，安装包使用 ad hoc 签名。

发布验收要求最终应用包通过源码一致性、严格签名、内置依赖、原生控件、实际模型与错误处理检查。发布的 DMG 与 SHA-256 校验值必须对应同一个应用包；公开下载后再次验证校验值。模型音频测试与界面操作测试分别报告范围。
